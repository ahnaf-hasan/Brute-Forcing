### 🔐 Brute Force Attack – Educational Notes

### 📖 Introduction

A Brute Force Attack is a cybersecurity technique that attempts different password combinations to understand or test authentication security.

### 📚 Types of Brute Force

- Simple Brute Force
- Dictionary Attack
- Hybrid Attack
- Reverse Brute Force
- Credential Stuffing

### ⚙️ How It Works

- Identify an authentication system.
- Understand password security.
- Test password strength in an authorized lab.
- Analyze authentication responses.
- Evaluate security weaknesses.

### 🛠️ Common Tools

- Hydra
- John the Ripper
- Hashcat

### 🛡️ Prevention

- Use strong passwords.
- Enable Multi-Factor Authentication (MFA).
- Implement Rate Limiting.
- Monitor failed login attempts.
- Use account protection policies.
